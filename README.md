# Animal Behavior Prediction Using Machine Learning

**“Animal behavior prediction using machine learning methods”**

The goal of this project is to analyze and predict **mouse behavior** by combining:
- Pose estimation (AlphaTracker)
- Unsupervised learning and clustering
- Multimodal data (video keypoints + audio analysis)
- Machine learning evaluation metrics (MOTA, HOTA, IDF1, Track-mAP)
- Audio feature extraction (MFCC, spectral features)
- Principal Component Analysis (PCA)

The project leverages **computer vision, clustering, and audio signal processing** to better understand behavioral patterns in laboratory mice.

---

## 🚀 Main Features
- 🔍 **Pose estimation** from frontal and top-view recordings using AlphaTracker  
- 🐭 **Behavioral feature extraction** from pose keypoints  
- 🔊 **Audio preprocessing** of `.wav` files using Librosa (MFCC, spectral centroid)  
- 📉 **Dimensionality reduction** with PCA  
- 🔗 **Unsupervised clustering** of multimodal data (k-means)  
- 📈 **Model evaluation** using MOTA, HOTA, IDF1, and Track-mAP  
- 🖼️ **Visualization tools** for pose tracking, bounding boxes, and keypoints
